# Coverageの走査を打ち切るシェーピング計画の生成時間

2026年11月11日、[ADR 0042](../adr/0042-stop-at-saturated-coverage-digest.md) の変更前後をmacOS 27.0 arm64、rustc 1.99.0で測った。基点は追加フォントを含むコミット `f4478df` で、変更後は同じ基点にCoverageの要約を作るコードの変更を加えた。対象は[役割別計測](2026-11-11-extra-font-roles.md)と同じフェイス0、既定座標、既定feature、言語指定なしの入力である。

## シェーピング計画の生成

読み込み済みのフォントと解決済みの区間の性質を渡して `ShapePlan::new` を呼び、生成した計画を `black_box` に渡して解放した。200回の平均を1バッチとし、11バッチの中央値を1回の値とした。変更前・後・後・前・前・後の順に実行した。表は各方式3回の中央値で、単位はマイクロ秒である。

| フォントと入力 | 方向 | 変更前 | 変更後 |
| --- | --- | ---: | ---: |
| Source Han「漢字」 | TTB | 110.840 | 33.188 |
| Source Serif「office」 | LTR | 13.077 | 12.069 |
| Noto Sans Arabic「بِت」 | RTL | 11.623 | 11.429 |
| Noto Sans Hebrew「שָׁלוֹם」 | RTL | 4.688 | 4.531 |

## 最初のシェーピング

リポジトリのベンチマーク `sofel-bench --filter 'first shaping role-default-und'` を変更前、変更後の順に各1回実行した。フォントのバイト列を渡すところから最初の1行のシェーピングまでを含む。どちらも同じCライブラリにリンクし、releaseビルドを使った。値は標準ハーネスの中央値±中央絶対偏差で、単位はマイクロ秒である。

Source Hanの入力では最初のシェーピングが66.7%短縮した。Amstelvarの中央値は同じであり、改善幅は入力によって異なる。各ベンチマークの計測前にHarfBuzzとグリフID、クラスタ、フラグ、位置を比較した。`SOFEL_REQUIRE_TESTDATA=1` を指定した既存の `shape_hash` は、native版とWasmtime 50.0.1で実行したwasm32-wasip1版の両方で固定コーパスの期待値に一致した。
