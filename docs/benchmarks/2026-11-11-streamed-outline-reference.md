# FreeTypeの輪郭参照の逐次比較（2026-11-11）

[ADR 0040](../adr/0040-stream-outline-reference.md) の変更前後で、固定コーパスの輪郭検証を単体で1回ずつ測った。両方とも532,841件を比較し、失敗は0件だった。

| 方式 | 実時間 | 子孫プロセスを含むRSSの最大観測値 | 観測回数 |
| --- | ---: | ---: | ---: |
| 全文と全ケースの識別子を保持 | 17.86秒 | 466,640 KiB | 123 |
| グリフ単位で比較 | 10.72秒 | 15,584 KiB | 75 |

基点は `f4478df` である。変更前には同じコミットの統合計測で使った輪郭テストの実行ファイル、変更後には同じコミットに[ADR 0037](../adr/0037-stream-raster-reference.md)と0040の変更を加えてビルドした実行ファイルを使用した。macOS arm64の同じホスト上で、両方に同じテストデータと `ft-dump` を環境変数で指定した。参照実行ファイルのSHA-256は `7c751a54ba15b7e1573c562d42f3be8140eef38450044e80a0f8277137f48bd4` である。

両方ともビルド済みのrelease実行ファイルを、変更前、変更後の順に次のコマンドで測った。TEST_BINARYは比較する実行ファイルのパスに置き換える。

```sh
/usr/bin/time -p sh scripts/measure-process-tree.sh TEST_BINARY \
  outlines_agree_with_freetype --exact --nocapture --test-threads=1
```

RSSは0.1秒間隔を目標に採取したプロセスツリーの合計で、共有ページを重複して数え、採取間のピークは見逃し得る。実時間の差は7.14秒だった。CI全体の完了時間への影響は未測定である。
