# ADR 0099: 条件番号を決められないテストを一覧に記録して検査から除く

Status: accepted

## 文脈

[ADR 0089](0089-invariant-numbers-and-test-names.md) は、条件番号を決められないテストの名前を維持し、一覧にしてメンテナーに示すと決めた。
同時に、ADR 番号を含むすべてのテスト名について、形と参照先の条件番号を検査すると決めた。
条件番号を持たない ADR のテストは、この二つを同時に満たせない。
指示者は2026年11月22日に、番号を決められないテストを一覧に記録し、検査で明示的に除外する方針を選んだ。

## 調査した事項

- main `81537c2e` の [ADR 0022](0022-subsetting.md) には「不変条件」と「受けいれ条件」の節がない。
- 同じコミットの `crates/sofel-subset/tests/layout.rs` には `adr0022_negative_gpos_advance_is_not_a_variation_index` など、ADR 番号だけを含むテスト名がある。
- [ADR 0089](0089-invariant-numbers-and-test-names.md) は、条件の節がない ADR に節を足すことを対象外にしている。

## 実装すること

`scripts/test-name-exceptions.tsv` に、条件番号を決められない既存のテストを記録する。
列はリポジトリ相対のファイルパス、テスト名、除外理由の三つとし、タブで区切る。
空行と先頭が `#` の行を除く各行は、三つの列をすべて持つ。
テスト名は、Rust では関数名、シェルではテストの名前の文字列である。

`scripts/check-test-names.sh` は、ファイルパスとテスト名がともに一致する登録だけを、名前の形と条件番号の検査から除く。
登録されていないテストには [ADR 0089](0089-invariant-numbers-and-test-names.md) の検査を適用する。
同じパスと名前の重複、空の理由、見つからないテストの登録は失敗とする。
登録されたテストの実行は通常どおり続ける。

条件番号との対応が確定したら、同じ変更でテスト名を直して登録を削除する。
初回の一覧は実装の PR で示す。
この ADR は [ADR 0089](0089-invariant-numbers-and-test-names.md) の「揃った形を保つ検査」と不変条件 I1、I2 を、上記の登録を除いたテストに適用するよう変更する。

## 実装しないこと

- ファイル全体や ADR 全体の除外。
- テストの実行や、条件の本文の変更。

## 不変条件

- I1: 登録のないテストに、[ADR 0089](0089-invariant-numbers-and-test-names.md) と同じ検査を適用する。
- I2: 登録とパスと名前が完全一致するテストだけを、名前の形と参照先の検査から除く。
- I3: 重複、空の理由、存在しないテストを含む一覧では検査が失敗する。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| 空の一覧 | 全テストを通常の規則で検査する | I1 |
| 既存テストのパスと名前と理由が一件ある | そのテストの名前の検査だけを除く | I2 |
| 同名のテストが別のファイルにある | 別のファイルのテストを通常の規則で検査する | I1, I2 |
| 同じパスと名前が二行ある | 失敗する | I3 |
| 理由が空 | 失敗する | I3 |
| 登録したテストが削除された | 失敗する | I3 |

## 受けいれ条件

- A1: 初回の一覧に、除外した各テストの理由が記録され、CI で一覧とテスト名の検査が成功する。

## テスト設計

`scripts/tests/test-check-test-names.sh` に `ADR 0099 I1`、`ADR 0099 I2`、`ADR 0099 I3` を含む名前のテストを置く。
境界の表の各行について、終了コードと診断に含まれるパスとテスト名を確かめる。

## トレードオフ

除外したテストには、名前から条件番号をたどれないものが残る。
理由と対象を一件ずつ記録するため、除外の範囲をレビューできる。
テストの削除や移動では、一覧も同じ変更で直す必要がある。
