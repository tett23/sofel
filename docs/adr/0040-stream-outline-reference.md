# ADR 0040: 輪郭の適合テストでグリフ単位の参照比較を共用する

ステータス: 採択

## 文脈

[ADR 0037](0037-stream-raster-reference.md) の参照パーサーは、FreeTypeの出力をフェイスとグリフの境界で区切って比較する。輪郭の適合テストでも、同じ参照ツールが同じ境界を出力する。現在の輪郭検証はフォントとサイズごとの出力全文を保持し、成功した全ケースの識別子も最後まで保持する。

## 実装すること

ラスタ検証と輪郭検証で、参照パーサーと期待する失敗の集計を共用する。輪郭検証ではグリフごとに命令列、overlapと制御箱を比較する。スケールはフェイスとサイズごとに求める。参照が開けなかったフォントと対象外のフェイスの扱いは[ADR 0037](0037-stream-raster-reference.md)と同じにする。

## データ構造とアルゴリズム

現在のフェイスの輪郭ビューとスケールを再利用する。参照の保持量は一つのグリフの行数と各行の長さに依存する。問題一覧には回帰、予期しない成功、未実行を従来と同じ順序で記録する。出力先は従来の `target/conformance/outline.problems` を使う。

## 実装しないこと

製品の輪郭描画アルゴリズムとFreeType参照の変更は対象外とする。

## 不変条件

1. 拡大縮小なし、16画素、48画素の各グリフで、識別子と命令列、overlap、制御箱の比較結果は全文パーサーと一致する。
2. 異なるグリフの命令列を混ぜず、エラーになったグリフは既存と同じ正規化済みの行として比較する。

| 入力 | 比較対象 |
| --- | --- |
| 空のグリフ | overlapと制御箱 |
| 命令を持つグリフ | 全命令、overlapと制御箱 |
| エラーの次に正常なグリフ | エラー行と次の命令列を別々に比較 |

## テスト設計

既存の正方形と二次曲線を含むFreeType参照テストに、全文パーサーと逐次パーサーの全グリフの照合を追加する。エラーの次に正常な命令列がある小さな入力も比較する。固定コーパスの輪郭検証を前後で実行し、件数、失敗数、時間と子孫プロセスのRSSを測る。

## トレードオフ

パイプを通して比較中のグリフだけを読み取るため、参照側は読み取りを待つことがある。2並列の完了時間への効果は単体の測定からは決められない。
