# ADR 0070: sfnt フォントを WOFF と WOFF2 に書き出す

ステータス: 採択

## 文脈

Web 配布用に、元のフォント全体も、必要なグリフだけを残したサブセットも WOFF または WOFF2 に変換したい。
[ADR 0001](0001-project-goal-and-scope.md) と [ADR 0022](0022-subsetting.md) が対象外とした書き出しのうち、この2形式をプロジェクトの範囲に加える。
サブセット化の出力は引き続き sfnt とし、そのバイト列を次のコマンドに渡して変換する。

## 調査した事項

[サブセット CLI](../../crates/sofel-cli/src/subset.rs) は出力先に標準出力を選べる。
既存の --output-format は hb-subset に合わせて受理するだけである。
[ADR 0003](0003-crate-layers.md) では sofel-woff に読み込みを割り当てている。
WOFF 1.0 は表ごとに zlib 圧縮を選び、短くならない表を元のバイト列で格納する。
WOFF2 は表をまとめたストリームを Brotli で符号化する。
WOFF2 の glyf と loca はどちらも変換なしで格納できる。

## 実装すること

sofel-woff に、単一フェイスの sfnt バイト列と出力形式を受け取り、完成したバイト列またはエラーを返す Rust API を追加する。
CLI は sofel-woff --format woff|woff2 INPUT -o OUTPUT とし、入力と出力それぞれでハイフンを標準ストリームとして扱う。
たとえば sofel-subset の標準出力を次のコマンドへ渡せる。

```sh
sofel-woff --format woff2 - -o subset.woff2
```

表のタグ、オフセット、長さ、チェックサムとフォント全体のチェックサムを検査してから符号化する。
WOFF ではディレクトリをタグ順に並べ、表本体は入力の物理順を保って4バイト境界に置く。
WOFF への往復で失われる余分なバイトや不正なパディングのある入力はエラーにする。
WOFF2 の初版は全表を変換なしで格納し、glyf と loca の変換版を3、他の表を0とする。
WOFF2 の表ディレクトリと圧縮前の表データには同じ順序を使い、loca は glyf の後に置く。
WOFF2 では DSIG を取り除き、head.flags のビット11を立てる。
圧縮は Rust で実装し、既存の展開だけを使うクレートにエンコーダへの依存を加えない。
メタデータと private data の任意ブロックは生成せず、対応するヘッダ値をゼロにする。

## 実装しないこと

初版の入力は TrueType、CFF、CFF2 の単一フェイスの sfnt とする。
TTC と OTC を丸ごと WOFF2 コレクションにする機能、および glyf、loca、hmtx のサイズ削減用の変換は後続の設計に残す。
圧縮率と処理速度の最適化は全機能の実装後に扱う。

## 不変条件

1. WOFF を入力の表順で sfnt に復元すると入力とバイト単位で一致する。WOFF2 を復元すると、DSIG の削除、head.flags のビット11、再計算した head.checkSumAdjustment を除き、flavor、表タグの集合と表の内容が入力と一致する。
2. WOFF では各表の格納長が元の長さ以下になり、同じ長さなら元のバイト列を格納する。WOFF2 では変換なしの全表を規格に従って復元できる。
3. 空入力、コレクション、壊れたディレクトリ、チェックサム不一致、長さのあふれはエラーにする。入力の検証または符号化に失敗した場合、出力ファイルを作成・上書きせず、標準出力にも書かない。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 全グリフのフォント、1グリフだけを残したサブセット、未知の表タグを含むフォント | 両形式で条件1を満たす |
| zlib 圧縮で1バイト短い、同じ長さ、1バイト長い表 | 最初の表だけを圧縮して条件2を満たす |
| 表長が4バイト境界の前後、glyf と loca を持つフォント、CFF2 フォント | パディングを表長に加えず条件1と2を満たす |
| 空入力、表末尾が1バイト不足、TTC、32ビット長を超える計算結果 | 条件3を満たす |

## テスト設計

I1_webfont_roundtrip は WOFF と WOFF2 対応を正常入力で確認した FreeType で全表を取り出して比較する。
WOFF の表本体をオフセット順に復元し、ディレクトリのタグ順と物理順が異なる入力でも全バイトを比較する。
DSIG（デジタル署名表）の有無と head.flags のビット11が0または1の入力を組み合わせ、WOFF での保持と WOFF2 での署名除去およびビット設定を検査する。
固定フォントと可変フォントを使い、通常のファイル入力と sofel-subset からのパイプを同じ検査に通す。
I2_webfont_directory はヘッダ、表の長さ、チェックサム、パディング、変換版を直接検査し、圧縮ストリームを独立したデコーダで展開する。
I3_webfont_error は既存ファイル、存在しないファイル、標準出力に対する失敗を CLI の終了コードと出力内容で検査する。
長さの上限はヘッダ寸法の計算に境界値を渡して検査する。

## トレードオフ

専用コマンドに分けると、全グリフを保つ変換でもサブセットの指定が要らず、既存の hb-subset 互換オプションも保てる。
WOFF2 の変換なしの表は照合しやすい一方、グリフ専用の変換を使うエンコーダよりファイルが大きくなる場合がある。
