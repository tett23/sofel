# ADR 0066: カラーグリフの画像を復号し、塗りを画素に合成する

ステータス: 採択（未実装）

## 文脈

[ADR 0023](0023-color-glyphs.md) は色やクリップを描画先に伝える Painter と、埋め込み画像を取り出す処理を定めた。
描画命令が一致していても、画素の順序やアルファの乗算が違えば絵文字の色は変わる。

## 調査した事項

[ft-dump](../../tools/ft-dump/ft-dump.c) の --sbit はストライクを選び、読み込みに成功したグリフについて行ごとの画素を出力する。
手元の参照ビルドで NotoColorEmoji.subset.ttf を渡すとグリフ1から5はエラー7（未対応）になった。
[hb-dump](../../tools/hb-dump/hb-dump.cc) の --paint で chromacheck-svg.ttf のグリフ1を調べると、SVG 画像の命令を出力した。
この出力には SVG を描いた画素は含まれない。

## 実装すること

sofel-inflate で DEFLATE、zlib、gzip を展開し、sofel-png で色型、ビット深度、フィルタ、インターレース、パレットと透過を処理する。
CRC と Adler-32 を各形式に従って検査する。
sofel-bitmap は復号した画像を FreeType と同じ乗算済み BGRA で返す。
sofel-raster に輪郭クリップと乗算済み RGBA の描画面を置く。
sofel-color がグリフを輪郭へ解決し、呼び出し側が渡した描画面を通して、線形、放射、扇形グラデーション、3種の延長、28種の合成、変換した画像の双線形サンプリングを描画面に渡す。
OT-SVG の gzip を展開し、公開する画像には展開済みのバイト列と Svg { gzip: false } を渡す。
sofel-svg でグリフに対応する要素を選ぶ。
パス、スタイル、変換、グラデーション、use、clipPath、context-fill を Painter の命令に変換する。
CLI の sofel-render --color からもこの経路を使う。

## 実装しないこと

SVG のスクリプト実行と外部リソースの取得は対象外とする。

## 不変条件

1. CBDT と sbix の PNG はストライク、原点、寸法、乗算済み BGRA の全画素が PNG 対応の FreeType と一致する。
2. 同じサイズ、原点、パレットと軸座標で、COLRv0 の画素は従来どおり FreeType と一致する。COLRv1 の画素は HarfBuzz raster の BGRA を RGBA 順に並べた8ビット値と全チャンネルが一致する。
3. 同じ SVG 文書を非圧縮と gzip で格納した場合、選ばれるグリフと全画素が一致する。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 1画素の PNG、アルファ0、半透明、完全不透明 | 各色型で条件1を満たす |
| 空のクリップ、境界上の色停止点、透明な前景または背景 | 各合成モードで条件2を満たす |
| 1文書に2グリフ、同じ文書を gzip で格納 | 各グリフで条件3を満たす |

## テスト設計

I1_sbit_png は既知の PNG 入りグリフの参照ロード成功を先に確認し、論理行の全画素を比較する。
I2_colr_pixels は塗り命令の照合に加えて、同じ描画面に描いた参照画素を読み、最初に異なる座標とチャンネルを報告する。
I3_svg_pixels は圧縮前後の比較に加え、単色矩形、重なるパス、クリップ、前景色を指定した合成入力について、Painter が受け取る画像のバイト列と gzip フラグを検査する。
同じ合成入力について手計算した内点と外点の色を検査する。
展開器単独では配布元とライセンスを確認して testdata.lock に固定した参照テストを使い、全色型とビット深度、壊れた CRC と Adler-32 を検査する。
SVG の図形境界は同じパスを直接 Painter に渡した結果と比較する。

## トレードオフ

COLR の画素一致を求めるため、補間と丸めの順序も参照実装に合わせる必要がある。
SVG では塗り命令と既知の図形を別々に検査するため、参照実装から SVG データを受け取れただけで画素の検査が通ることを避けられる。
