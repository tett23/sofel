# ADR 0061: 軸を固定または制限して可変フォントを書き出す

ステータス: 採択

## 文脈

[ADR 0022](0022-subsetting.md) は軸の範囲を入力する API を定め、任意位置への固定と部分的なインスタンス化を後続の設計に残した。
軸の範囲を狭めると、新しい既定位置での値と、その位置からの変化量をともに書き直す必要がある。

## 調査した事項

[ADR 0022](0022-subsetting.md) の「後回しにしたもの」には対象の表と CLI の入力形式が列挙されている。
固定した HarfBuzz の src には hb-subset-instancer-solver.cc、hb-subset-instancer-iup.cc と解法の単体テスト test-subset-instancer-solver.cc がある。

## 実装すること

既存のサブセット計画に軸ごとの入力範囲と出力範囲の対応を保持する。
入力は既存の軸指定 API と CLI の --instance から受け取る。
fvar と avar の写像を適用し、固定した軸の寄与を既定値へ移し、残る軸の補間領域を新しい座標系で表す。
gvar、cvar、CFF2 と各 ItemVariationStore の変化量を更新し、メトリクス、輪郭、色、レイアウトからの参照を同じ計画で書き直す。
FeatureVariations の条件を新しい軸範囲で評価し、軸と名前の情報も更新する。
CFF2 の blend の丸めと DOWNGRADE_CFF2、COLRv1 の定数になった塗りを更新する。
VARC の部品を含む入力は [ADR 0067](0067-varc-components.md) の成否の条件に従う。
IUP による点の省略は hb-subset の対応するフラグに従う。

## 実装しないこと

破損した表には [ADR 0022](0022-subsetting.md) のエラーと出力検証の条件を適用する。
このサブセット化の出力は sfnt とする。
生成した sfnt の WOFF と WOFF2 への変換は [ADR 0070](0070-webfont-encoding.md) で扱う。

## 不変条件

1. 正常なフォントで参照実装が成功する場合、同じフォント、軸指定、グリフ集合、フラグから書いた sfnt の全バイトが、固定した hb-subset の出力と一致する。
2. 存在しない軸の設定は失敗し、その前に設定した軸範囲を変えない。

| 境界の入力 | 判定 |
| --- | --- |
| 軸指定なし、全軸を既定値に固定 | 従来の入力でも条件1を満たす |
| 1軸を端点に固定、複数軸の一部だけ固定 | 残る軸と出力の表が条件1を満たす |
| 最小値と既定値が等しい範囲、既定値と最大値が等しい範囲 | 非対称な範囲でも条件1を満たす |
| 有効な指定の直後に未知の軸を指定 | 条件2を満たす |

## テスト設計

I1_subset_instance は既存のサブセット適合テストに上表の入力を加え、IUP フラグの有無、avar の両版、FeatureVariations を含む入力を比較する。
差が出たら、最初に異なる表と位置を示す。
I2_unknown_axis は失敗の前後に同じ計画を作り、出力を比較する。

## トレードオフ

バイト一致には領域と行の並べ方や丸めの順序まで合わせる必要がある。
その代わり、輪郭だけの検査では見落とすレイアウトやメタデータの差も検出できる。
