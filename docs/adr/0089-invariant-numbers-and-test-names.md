# ADR 0089: 不変条件と受けいれ条件の番号と、テストの名前を決まりの形に揃える

Status: superseded-pending [{"part":"揃った形を保つ検査と不変条件 I1、I2","by":["docs/adr/0099-test-name-reference-exceptions.md"]}]

## 文脈

メンテナーの全リポジトリの決まり（dotfiles ADR 0124）は、不変条件の番号を `I1`、`I2`、…、受けいれ条件の番号を `A1`、`A2`、… とし、それを確かめるテストの名前にその番号を入れると定める。
識別子で名前を付けるテストは `adr<NNNN>_i<番号>_<内容>`、文字列で付けるテストは `ADR <NNNN> I<番号>: <内容>` の形にする。
同じ決まりは、決まりを入れた後に一度だけ、各リポジトリで、今ある ADR の番号とテストの名前を書き換えると定め、その書き換えは、そのリポジトリの ADR で行うとしている。

2026-11-17 の ADR 違反の監査は、低の指摘 L7 として、sofel のテストの名前がこの形に揃っていないことを挙げた。
この監査は会話で報告し、`docs/audits/` には記録していない（[ADR 0081](0081-crate-layout-corrections.md) と同じ扱いである）。
この ADR は、sofel での一度だけの書き換えと、その後に揃った形を保つ検査を決める。

## 調査した事項

### ADR の番号の形

`docs/adr/` の各 ADR の「不変条件」の節を、`awk` で取り出して数えた（この ADR を書いた時点の origin/main `df31e33a` と、提案中の [ADR 0085](0085-autofit-harfbuzz-configuration.md)〜0088 を含む）。

- 節の項目が `- I1` の形のもの: 5 件
- 節はあるが、ほかの形（`1.`、`I01`、`ADR0046-I1` など）のもの: 54 件
- 「不変条件」の節が無いもの: 29 件

各 ADR が書いたテストの名前の決まりも揺れている。
たとえば、[ADR 0031](0031-diverse-font-corpus.md) は「テスト名には `I01` などの番号を入れる」、[ADR 0046](0046-harfbuzz-lookup-variations.md) は「テスト名にADR0046-I1を入れる」と書く。

### テストの名前

`git grep -h -A3 '#\[test\]' -- 'crates/**/*.rs' 'tools/**/*.rs'` で Rust のテストの関数の名前を集めた。

| 分類 | 件数 |
| --- | --- |
| すべて | 1983 |
| `(^|_)adr[0-9]{4}_[ia][0-9]+_` の形に合う | 575 |
| `adr[0-9]{4}` を含むが、上の形に合わない | 108 |
| `adr[0-9]{4}` を含まない | 1300 |

- 形に合わない 108 件には、`adr0071_inv5_...` のように番号の書き方が違うものがある。
- `adr[0-9]{4}` を含まないテストには、不変条件や受けいれ条件を確かめないテスト（単体の関数の振る舞いを確かめるものなど）も含まれる。どれが不変条件を確かめるかは、名前だけでは決まらない。
- シェルのテスト（`scripts/tests/`）は、`ADR 0080 I1:` のように文字列の名前を付けるものがある。

## 実装すること

### 一度だけの書き換え

- コミット済みの ADR の「不変条件」と「受けいれ条件」の番号を、`I1`、`A1` の形に書き換える。番号の順は今の順のままとし、中身は変えない。
- 改善項目など、不変条件でも受けいれ条件でもない番号は変えない。
- 飛び番号（`I01`、`I02`、`I04` など）は詰めず、元の数のまま `I1`、`I2`、`I4` とする。
- ほかの ADR の本文が番号を引く箇所（「不変条件1」など）は、リンクと同じく、同じコミットで新しい番号に直す。
- 不変条件か受けいれ条件を確かめるテストの名前を、決まりの形に書き換える。Rust のテストと、文字列で名前を付けるシェルのテスト（`scripts/tests/`）の両方を対象にする。どの番号を確かめるかは、テストの注釈、テストのファイル、ADR のテスト設計を読んで決める。
- 名前から番号を決められないテストは書き換えず、一覧にしてメンテナーに示す。
- ADR の書き換えは、その書き換えだけの一つのコミットにする。pre-commit の hook は `ADR_GUARD_ALLOW` で、CI はコミットのメッセージのトレーラー `ADR-Guard-Allow:` で許す。理由には `dotfiles ADR 0124` と書く。
- テストの名前の書き換えは、ADR の書き換えとは別のコミットにする。

### 揃った形を保つ検査

- `scripts/check-test-names.sh` を足し、CI で動かす。
- Rust のテストの名前は、`#[test]` の属性の後に最初に現れる `fn <名前>` から取る。属性と注釈の行数に依らずに取る。
- 検査は、Rust のテストの名前のうち `adr[0-9]{4}` を含むものが、決まりの形（`adr<NNNN>_[ia]<番号>(_[ia]<番号>|_adr<NNNN>_[ia]<番号>)*_<内容>`）に合うことを確かめる。sofel の ADR は `docs/adr/` の一つだけなので、モジュールの名前の接頭辞は許さない。
- シェルのテストは、名前の文字列が `ADR [0-9]{4}` を含むものが、`ADR <NNNN> I<番号>: ` の形（番号の並びは `, ` で区切る）で始まることを確かめる。
- 検査は、名前の ADR の番号のファイルが `docs/adr/` にあり、名前の `I` と `A` の番号がその ADR の節にあることも確かめる。

## 実装しないこと

- `adr[0-9]{4}` を含まないテストに、機械的に番号を付けること。不変条件を確かめないテストもあるためである。
- 不変条件と受けいれ条件の中身の変更。中身を変えるときは、新しい ADR を作る。
- 「不変条件」の節が無い ADR に、節を足すこと。

## 不変条件

- I1: `adr[0-9]{4}` を含む Rust のテストの名前と、`ADR [0-9]{4}` を含むシェルのテストの名前は、どれも決まりの形に合う。
- I2: テストの名前が指す ADR のファイルがあり、名前の `I` と `A` の番号はその ADR の「不変条件」か「受けいれ条件」の節にある。
- I3: 書き換えの前後で、各 ADR の不変条件と受けいれ条件の本文（番号を除く）は同じである。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| テストが一つも無い | 検査が通る | I1, I2 |
| `adr0064_i1_auto_slots_match_freetype` | 検査が通る | I1, I2 |
| `adr0071_inv5_...` | 検査が失敗し、名前を出す | I1 |
| `adr0064_i9_...`（[ADR 0064](0064-freetype-hinting-and-render-modes.md) に I9 が無い） | 検査が失敗し、名前を出す | I2 |
| `adr9999_i1_...`（ADR 9999 が無い） | 検査が失敗し、名前を出す | I2 |
| `adr0061_i1_adr0022_i2_...`（二つの ADR にまたがる） | 検査が通る | I1, I2 |
| `wide_adr0004_i1_x`（接頭辞つき） | 検査が失敗し、名前を出す | I1 |
| `#[test]` と `fn` のあいだに属性が 5 行ある | 名前を取りこぼさない | I1 |
| シェルのテストの `ADR 0080 I1, I2: ...` | 検査が通る | I1, I2 |
| 書き換えたコミットの差分 | 各行の違いが番号だけ | I3 |

## 受けいれ条件

- A1: `scripts/check-test-names.sh` が main で通り、CI で動く。
- A2: 書き換えられなかったテストの一覧を、書き換えのプルリクエストに書く。

## テスト設計

- `ADR 0089 I1: ...`、`ADR 0089 I2: ...`: `scripts/tests/test-check-test-names.sh` で、一時ディレクトリに境界の表の各行の名前のテストと ADR を作り、検査の終了コードと出力を確かめる。
- `ADR 0089 I3: ...`: 書き換えのコミットの差分を、番号を正規化してから比べるシェルのテストで確かめる（書き換えのプルリクエストで一度動かす）。

## トレードオフ

- 54 件の ADR と多数のテストの名前を書き換えるので、一度に大きな差分が出る。一方、監査と検査が、番号からテストを機械的にたどれるようになる。
- `adr[0-9]{4}` を含まないテストは検査の外に残る。不変条件を確かめるのに番号の無いテストは、レビューと監査で見つける。
