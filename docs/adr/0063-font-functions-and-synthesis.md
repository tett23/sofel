# ADR 0063: サブフォントの関数と合成太字、合成斜体を適用する

ステータス: 採択（未実装）

## 文脈

シェーピング中に使う送りや輪郭の供給元を差し替えるアプリケーションがある。
合成した書体では描画と配置にも同じ設定が要る。

## 調査した事項

[ADR 0016](0016-font-and-vertical-metrics.md) はフォント関数と合成書体を後続の設計に残した。
HarfBuzz の hb_font_create_sub_font は親のスケール、ppem、ポイントサイズ、合成設定、軸座標を子の作成時に引き継ぐ。

## 実装すること

親への参照と関数ごとの上書きを子に保持する。
文字からのグリフ検索、送り、原点、箱、輪郭の各問い合わせは子の関数を優先し、未指定の問い合わせを親に委ねる。
親から返る座標は問い合わせに応じて子のスケールに換算する。
HarfBuzz の合成設定は配置と輪郭に反映し、FreeType のスロットの太字、斜体およびビットマップの太字は FreeType 用の操作として提供する。
ビットマップの画素形式変換は FT_Bitmap_Convert と照合し、画像に渡す斜体の値も HarfBuzz の描画命令と照合する。

## 実装しないこと

実フォントのスタイル選択は呼び出し側に委ねる。

## 不変条件

1. 同じ関数と親子スケールを設定したとき、各問い合わせとグリフ列は HarfBuzz と一致する。
2. 各合成操作で変更した送り、箱、輪郭またはビットマップはその操作の参照実装と一致する。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 上書きなし、一つだけ上書き、親子のスケールが異なる | 条件1を満たす |
| 合成量0、斜体だけ、太字の in_place の両値 | 条件2を満たす |

## テスト設計

I1_subfont は親だけにある送り関数と子だけにあるグリフ検索を組み合わせる。
I2_synthetic はグリフの送りと輪郭を HarfBuzz と、スロットとビットマップを FreeType と別々に照合する。

## トレードオフ

親子間の換算と各参照実装の合成手順を分けて保守する必要がある。
