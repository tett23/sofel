# ADR 0088: 自作した最小のテスト入力と、その参照出力をリポジトリに置く

Status: accepted-pending

## 文脈

[ADR 0002](0002-license-and-reuse.md) は、テストのフォントをリポジトリに同梱しないと決めた。
理由は、ライセンスを確かめられないフォントを再配布しないためである。

2026-11-17 の ADR 違反の監査は、低の指摘 L6 として、リポジトリにフォントの形式のファイルが置かれていることを挙げた。
この監査は会話で報告し、`docs/audits/` には記録していない（[ADR 0081](0081-crate-layout-corrections.md) と同じ扱いである）。
調べると、置かれているのは、実在のフォントではなく、テストのために作った小さなファイルと、それを入力にして HarfBuzz が出した参照の出力だった。
この ADR は、[ADR 0002](0002-license-and-reuse.md) の「テストのフォント」がこれらを含むかを決め、置いてよいものと、置くときの記録を定める。

## 調査した事項

`git ls-files | grep -i -E '\.(ttf|otf|ttc|otc|bdf|pcf|fon|fnt|pfb|pfa|pfr|woff2?|t42|cff|dfont)$'` で、フォントの形式の拡張子のファイルを数えた。

| 場所 | 件数 | 中身 | 由来の記録 |
| --- | --- | --- | --- |
| `crates/sofel-subset/tests/data/` | 18 | `*-hb15.ttf`、`*-hb15.otf`（312〜444 バイト） | テストが組んだバイト列を入力にした `hb-dump --subset` の出力。コマンドはテストの注釈にある（`crates/sofel-subset/tests/cff2.rs:251-253`、`tests/instance.rs:412-413`） |
| `crates/sofel-bitmapfont/tests/data/` | 12 | BDF 5、PCF 3、FNT 2、FON 2（160〜1184 バイト） | 作り方の記録が無い。最初のコミットは `f533af25`（PCF 3件）、`d447722e`（FNT 2件と `two.fon`）、`65370587`（`mono-pe.fon`）、`0d04001d`（BDF 5件）で、メッセージに作り方は書かれていない |
| `crates/sofel-shape/tests/support/` | 1 | `type1_triangle.pfa`（1631 バイト）。先頭は `%!PS-AdobeFont-1.0: Test 1.0` | 作り方の記録が無い。最初のコミットは `7767d3d4` |

- 実在のフォントは、この検索では見つからなかった。
- [ADR 0002](0002-license-and-reuse.md) の「テストのデータ」は「テストのフォントはsofelのリポジトリに同梱しない。」と書き、「実装しないこと」は「テストのフォントの同梱。ライセンスを確かめられないものを再配布しない。」と書く。

HarfBuzz の出力の著作権の扱い（プログラムの出力にプログラムのライセンスが及ぶか）は、この ADR では確かめていない（未確認）。
出力の中身は、sofel のテストが組んだ入力から決まる。

## 実装すること

### 置いてよいもの

次の二つは、[ADR 0002](0002-license-and-reuse.md) の「テストのフォント」に含めず、リポジトリに置いてよい。

1. sofel の開発者が、テストのために一から作った最小の入力（フォントの形式のファイルを含む）。sofel のライセンスで配布する。
2. 1 を入力にして、固定した版の HarfBuzz か FreeType が出した参照の出力。

実在のフォント、実在のフォントから作ったファイル、ライセンスを確かめられないファイルは、これまでどおり置かない。

### フォントの形式のファイル

この ADR で「フォントの形式のファイル」は、拡張子が次のどれかのファイルとする。
拡張子の大文字と小文字は区別しない。
`ttf`、`otf`、`ttc`、`otc`、`bdf`、`pcf`、`fon`、`fnt`、`pfb`、`pfa`、`pfm`、`afm`、`pfr`、`woff`、`woff2`、`t42`、`cff`、`dfont`

### 置くときの記録

- 置くファイルごとに、作り方を記録する。記録は、同じディレクトリの `README.md` に書く。
- `README.md` には、ファイルごとに `## <ファイル名>` の見出しを置き、その下に作り方を書く。
- 作り方は、次のどちらかで書く。
  - そのファイルを作り直すコマンド（参照の出力なら、参照の道具、版、引数、入力）
  - 手で書いたファイルなら、手で書いたことと、テキストの形式ならそのまま読めること
- いまの `sofel-bitmapfont/tests/data/` の 12 件と `sofel-shape/tests/support/type1_triangle.pfa` は、作り方を確かめて記録する。作り方を確かめられないファイルは、テストのコードの中でバイト列を組むように書き直してから消す。

### 確かめる仕組み

- `scripts/check-fixtures.sh` を足し、`git ls-files` のうちフォントの形式のファイルが、置いてよい場所（`crates/*/tests/data/`、`crates/*/tests/support/`）にあり、同じディレクトリの `README.md` に、そのファイル名の `## <ファイル名>` の見出しがあることを確かめる。CI で動かす。
- いま `crates/sofel-subset/tests/cff2.rs` と `tests/instance.rs` の注釈に書いた作り方は、`README.md` に写す。

### [ADR 0002](0002-license-and-reuse.md) のステータス

- この ADR を採択したら、[ADR 0002](0002-license-and-reuse.md) のステータスに、`"part":"テストのデータ"`、`"kind":"supplement"` の変更を記録する。[ADR 0002](0002-license-and-reuse.md) の決まりを置き換えず、「テストのフォント」の範囲を補うためである。

## 実装しないこと

- 実在のフォントの同梱。[ADR 0002](0002-license-and-reuse.md) と [ADR 0083](0083-cff-random-gallery-sample.md) のとおり、取得して使う。
- 参照の出力を CI で毎回作り直すこと。参照の道具のビルドを要するテストが増えるためである。作り直すコマンドの記録で、再現できることを保つ。

## 不変条件

- I1: リポジトリのフォントの形式のファイルは、どれも置いてよい場所にある。
- I2: リポジトリのフォントの形式のファイルは、どれも同じディレクトリの `README.md` に、そのファイル名の見出しを持つ。

| 入力 | 期待 | 不変条件 |
| --- | --- | --- |
| フォントの形式のファイルが無い | 検査が通る | I1, I2 |
| `crates/x/tests/data/a.ttf` があり、`README.md` に `## a.ttf` がある | 検査が通る | I1, I2 |
| `crates/x/tests/data/a.ttf` があり、`README.md` が無い | 検査が失敗し、パスを出す | I2 |
| `README.md` に `## b.ttf` だけがある | 検査が失敗し、`a.ttf` のパスを出す | I2 |
| `fonts/a.ttf`（置いてよい場所の外） | 検査が失敗し、パスを出す | I1 |
| 拡張子が大文字の `A.OTF` | 拡張子を大文字と小文字で区別せずに扱う | I1, I2 |

## 受けいれ条件

- A1: `scripts/check-fixtures.sh` が main で通り、CI で動く。
- A2: `sofel-bitmapfont` と `sofel-shape` の既存のファイルについて、作り方の記録があるか、テストのコードで組むように書き直してある。

## テスト設計

- `ADR 0088 I1: ...`、`ADR 0088 I2: ...`: `scripts/tests/test-check-fixtures.sh` で、一時ディレクトリの git リポジトリに境界の表の各行の配置を作り、検査の終了コードと出力を確かめる。

## トレードオフ

- 小さな入力と参照の出力を置くので、テストが参照の道具のビルドを待たずに動く。一方、置くファイルごとに作り方を記録する手間が増える。
- 参照の出力の著作権の扱いは未確認である。出力の中身は sofel のテストの入力から決まるので、問題は小さいと考える（推測）。問題が分かれば、テストの実行時に作る形に変える。
