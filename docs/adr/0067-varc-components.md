# ADR 0067: VARC の条件付き部品を指定座標で展開する

ステータス: 採択

## 文脈

VARC のグリフは別のグリフを部品として参照し、部品ごとに表示条件、変形、軸座標を指定する。
親の座標だけで各部品を描くと、非既定位置で形が変わる。

## 調査した事項

[ADR 0027](0027-variable-fonts.md) は VARC、MultiItemVariationStore、SparseVarRegionList を第13段階に残した。
固定した HarfBuzz の test/vector/data/tests/varc.tests には既定位置と wght=840.3 について、通常の部品と条件付き部品を組み合わせた4件がある。
test/api/test-subset-varc.c は、サブセット化の部品の閉包、再採番、軸固定の失敗、無関係な軸を指定した場合も扱う。

## 実装すること

sofel-read に VARC と変化量ストアのビューと検証器を置く。
輪郭取得時にはグリフごとに VARC の収録範囲を調べ、対象なら部品を記録順に処理する。
各部品の条件と座標の指定を評価し、部品用の位置と累積変換を子の呼び出しだけに渡す。
HarfBuzz の既定構成に合わせ、再帰の深さの予算は64、グリフごとに共有する辺数の予算は16384とする。
VARC の部品に入る時点で残りの深さか辺数が0なら、その部品の展開を止める。
現在の再帰経路に同じグリフが現れた場合も、その部品の展開を止める。
サブセット化では残す部品を再帰的に集め、グリフ ID と参照を書き直す。
軸固定の成否は同じ軸指定の hb-subset と照合する。

## 実装しないこと

VARC の収録範囲外の通常グリフには既存の輪郭処理を使う。

## 不変条件

1. 同じグリフと位置において描画命令の順序と変形後の座標は HarfBuzz の輪郭出力と一致する。
2. 正常な VARC 表のサブセットの成否と成功時のバイト列は同じ指定の hb-subset と一致する。
3. 部品の循環、範囲外参照、打ち切りがあっても有限回で終了し、次のグリフの位置と変換に影響しない。

| 境界の入力 | 期待する結果 |
| --- | --- |
| 表示条件の直前、境界ちょうど、直後。兄弟の片方だけに座標指定 | 条件1を満たす |
| 同じ部品を2回参照、グリフ番号を保持、対象の軸または無関係な軸を固定 | 条件2を満たす |
| 自己参照、2グリフの循環の直後に正常グリフを描く | 条件3を満たす |

## テスト設計

I1_varc_outline は上記4件と兄弟で位置の異なる入力を比較する。
I2_varc_subset は再採番後の部品の描画も比較する。
I3_varc_bounded は循環と深さと辺数それぞれの上限の直前、上限、超過を含む人工フォントを連続して読み、次の通常グリフを単独で描いた場合と照合する。

## トレードオフ

各部品の位置と変形を再帰呼び出しごとに保持する分、処理量の上限が必要になる。
親や兄弟に途中の状態が残らないため、異なる位置の部品を同じ輪郭取得処理で扱える。
