# フォントと sofel の用語集

文字列を描くとき、シェーピングが文字からグリフとその配置を決め、輪郭や画像がグリフの形を与え、ラスタライズが輪郭を画素に変える。各段階で使う語を処理順にまとめた。実装範囲は[仕様書](specifications.md)、Rust の型とクレートの対応は [API 文書](api.md)で確認できる。

## フォントの中身と寸法

| 用語 | 意味 |
| --- | --- |
| フェイス（face） | 個別に選んで使う書体データ。TTC や OTC は、一つのファイルに複数のフェイスを格納するコレクションで、フェイス番号で一つを選ぶ。 |
| sfnt、表（table）、タグ（tag） | sfnt はフォントのデータを表に分けて格納する形式。各表を識別する4バイトのタグと、その表の位置と長さを目録に記録する。タグは軸や機能の識別にも使う。 |
| コードポイント、グリフ、グリフ ID | コードポイントは Unicode の文字に割り当てられた数値。グリフはフォントが持つ字形で、グリフ ID はフェイス内の番号。同じ文字でも周囲の文字によって別のグリフを使うことがある。 |
| cmap | コードポイントから最初に使うグリフ ID を引く表。合字や文脈による字形の選択は後のシェーピングで行う。 |
| em、フォント単位、UPEM | em は文字の大きさの基準。UPEM（units per em）は 1 em に含まれるフォント単位の数。UPEM が 1000 なら、500 単位の送り幅は 0.5 em に当たる。 |
| ppem | pixels per em の略。1 em を何画素で描くかを表す。グリフごとの画像の高さは形によって異なる。 |
| ベースライン（基準線）、原点 | ベースラインは文字を並べるときの基準線。グリフの原点は、そのグリフの輪郭や配置の座標を測る起点。 |
| 送り幅（advance）、オフセット（offset） | 送り幅は次のグリフの原点へ進む量。シェーピングのオフセットは、現在のグリフの描画位置を原点からずらす量。 |
| 境界箱（bounding box、extents）、サイドベアリング | 境界箱はグリフの形を囲む長方形。横書きの左サイドベアリングは原点から形の左端までの距離。原点より左に線が張り出すと負になる。右端も送り幅を超えうる。 |
| アセンダー、ディセンダー、行間（line gap） | アセンダーとディセンダーはベースラインの上下の範囲を表すフォントのメトリクス。行間と合わせて行の配置に使う。個々の字形がこの範囲から張り出すこともある。 |

## シェーピングと配置

| 用語 | 意味 |
| --- | --- |
| シェーピング（shaping） | 文字列と、書字方向・文字体系・言語・有効な機能から、描画順のグリフ列とそれぞれの送り幅・オフセットを求める処理。 |
| クラスタ（cluster） | 出力グリフを入力文字列の位置に対応づける値。たとえば複数の文字が一つの合字になっても、その合字を入力に対応づけられる。 |
| feature、lookup | feature は `liga`（標準合字）や `kern`（カーニング）など、タグで選ぶ機能。lookup は機能が参照する置換・配置規則の単位。一つの機能が複数の lookup を使うこともある。 |
| GSUB、GPOS、GDEF | GSUB はグリフを置換する表、GPOS はグリフの配置を調整する表。GDEF は基底文字・合字・マークなどのグリフ分類や、配置が参照する変化量などを持つ。 |
| 合字（ligature）、異体字（alternate）、スワッシュ（swash） | 合字は複数のグリフをまとめた字形。異体字は同じ文字を表す別の字形。スワッシュは線を長く伸ばすなど装飾を加えた字形で、左右の文字の領域に届くことがある。 |
| カーニング、マーク、アンカー | カーニングは特定のグリフの組み合わせに応じた間隔の調整。アクセントなどのマークを基底グリフに重ねるときは、それぞれの基準点であるアンカーを合わせる。 |
| Coverage、ClassDef | OpenType の Coverage は対象グリフの集合と、集合内での番号を表す。ClassDef はグリフをクラス番号に割り当て、同じ規則を複数のグリフに適用する。 |
| FeatureVariations | 可変フォントの軸の位置に応じて、レイアウトに使う feature の定義を切り替える仕組み。 |

## 輪郭、カラー、画素

| 用語 | 意味 |
| --- | --- |
| 輪郭（outline）、制御点 | 輪郭は字形の境界を表す閉じたパスの集まり。曲線の形は端点と制御点で決まる。制御点は曲線上にあるとは限らない。 |
| glyf、loca、合成グリフ | TrueType の glyf 表は点列で表す単純グリフと、ほかのグリフを部品として変換・配置する合成グリフを格納する。loca 表は各グリフのデータ位置を示す。 |
| CFF、CFF2、charstring、Private DICT | CFF 系では charstring の命令列が輪郭を描く。Private DICT はヒントなどのパラメーターを持つ辞書。CFF2 の blend 命令では、軸の位置に応じて値を補間する。 |
| ヒンティング、ラスタライズ、画素被覆率 | ヒンティングは指定サイズでの見え方に合わせて輪郭などを調整する処理。ラスタライズは輪郭を画素に変換する処理。アンチエイリアスには、画素を形がどの程度覆うかを使う。 |
| COLR、CPAL、ストライク（strike） | COLR はグリフの重ね方や塗り方を表し、CPAL は塗りに使うパレットを持つ。ビットマップフォントのストライクは、ある画素サイズ向けのグリフ画像の組。 |
| サブセット化（subsetting） | 指定した文字やグリフと、それを表示するために必要な部品・レイアウト規則などを残してフォントを作り直す処理。 |

## 可変フォント

| 用語 | 意味 |
| --- | --- |
| 軸（axis）、設計座標、名前つきインスタンス | 軸は太さ（`wght`）や光学サイズ（`opsz`）などの変化の方向。設計座標は各軸で指定する値。fvar 表は軸の最小値・既定値・最大値と、座標の組に名前を付けたインスタンスを記録する。 |
| 正規化座標、avar | 各軸の設計座標を既定値が 0、両端が −1 と +1 の尺度に写した値が正規化座標。avar 表はこの写像を調整する。 |
| 固定小数点（2.14、16.16、26.6） | 小数部の桁数を決めて数値を整数で保存する方式。2.14 と 16.16 の最小刻みはそれぞれ 1/16384、1/65536。26.6 の画素座標なら整数値 64 が 1 画素を表す。 |
| 領域（region）、係数（scalar）、変化量（delta） | 領域はどの軸位置で一つの変化が効くかを記述する。係数は現在の位置での効き具合。各領域の変化量に係数を掛けて組み合わせ、既定の値を調整する。 |
| ItemVariationStore、VariationIndex | ItemVariationStore は領域と変化量の行を格納する。VariationIndex の outer はデータの組を選び、inner はその中の行を選ぶ。 |
| gvar、tuple、IUP、幻の点（phantom points） | gvar は TrueType グリフの点の変化量を、軸上のピークなどを持つ組（tuple）ごとに記録する。IUP は指定のない輪郭点の変化量を補間する手順。幻の点は横・縦のメトリクスを表す追加の4点で、輪郭を描く点列の外にある。 |
| HVAR、VVAR、MVAR | HVAR と VVAR はグリフごとの横・縦の送り幅やベアリングなどの変化量を持つ。MVAR はアセンダーなどフォント全体のメトリクスの変化量をタグで指定する。 |

## sofel の型と検証用語

| 用語 | sofel での意味 |
| --- | --- |
| HarfBuzz（HB）、FreeType（FT） | sofel が照合に使う参照実装。シェーピングや配置は主に HarfBuzz、輪郭やラスタライズは主に FreeType と比べる。同じフォントでも座標の精度や丸め順が異なるため、問い合わせごとに参照先を定めている。 |
| `Font`、`Location`、`Instance` | `Font` は一つのフェイスを読む値。`Location` は軸の位置と評価に使う情報を持つ。`Instance` はフォントと位置を組み合わせ、その位置のメトリクスなどを問い合わせる値。 |
| `HbF32`、`HbF64`、`Ft` | 変化量を求める際の演算方式。HarfBuzz の単精度・倍精度の計算と、FreeType の固定小数点の計算に対応する。丸めをどの段階で行うかも結果に影響する。 |
| `StoreScalars`、`OnTheFly` | 前者は位置に応じた領域係数を保存して再利用する方式。後者は問い合わせ時に係数を計算する方式。同じ入力を両方式で評価した結果をテストで照合する。 |
| `ShapePlan`、バッファ、scratch | `ShapePlan` はシェーピングで適用する機能や lookup を選んだ計画。バッファは処理中の文字・グリフと配置を保持する。scratch は計算で一時的に使い、繰り返し利用できる作業領域。 |
| `Pen`、`Painter` | `Pen` は移動・直線・曲線などの輪郭命令を受け取る。`Painter` はカラーグリフの塗り・変換・クリップなどの命令を受け取る。 |
| コーパス、face-location、参照ダンプ | コーパスは照合に使うフォントや入力の集合。face-location は一つのフェイスと一つの軸位置の組を数える単位。`hb-dump` と `ft-dump` が出力した参照値を、対応する sofel の値と照合する。 |
| ダイジェスト、期待する失敗（expected failure） | ダイジェストは一定の順序で並べた多数の結果をハッシュ値にまとめ、環境間の差を検出するために使う。期待する失敗は、参照実装との差を理由とともに記録し、新しい差を識別するための項目。 |
